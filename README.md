# CS Ops Copilot

AI agents that do the operational work of a Customer Success team, built on a
synthetic book of 40 accounts for an invented regtech SaaS (transaction
monitoring and regulatory reporting for banks and asset managers).

## What it does
- Account briefs: a one-page summary of any account before a call or QBR
- Health and renewal-risk scoring, with every reason tied to the data
- Onboarding watcher: flags accounts that are stalling
- Weekly digest for the CS team

## Status
Work in progress: an 8-week build, started November 2026.

## Data
All accounts, contacts and usage data are invented. Nothing comes from a real company.

## Built with
Claude Code, Python, SQLite, HubSpot (test account)
